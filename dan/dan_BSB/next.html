Write the style guide

The team's decisions, settled once and binding for every later chapter: how to write the divine names and the names, the quote marks, how formal the language is. Start from the first chapter's open questions. In Claude Code, in this folder:

Write the style guide for dan/dan_BSB with me

Draft the next chapters

One chapter after another, never several at once: each chapter's agent reads what the earlier chapters decided (names, word forms, spelling) and adds its own decisions to the memory, so the chapters stay consistent. One agent drafts a book, chapter by chapter, and checks each. In Claude Code:

Draft Malachi 4 for dan/dan_BSB

Show it to others: the website

The public website shows every project's drafts, marked as drafts, with the language memory and the credits; the text of a non-free translation never appears there, only short quotes within the limits. To put this project there, the files go into git and the site is deployed:

git add export/ import/ && git commit -m "…" && git push
python3 scripts/deploy_site.py

Or ask Claude Code to prepare it (it stages the files and gives you a commit message; you commit):

Stage dan/dan_BSB for the website and give me a commit message
